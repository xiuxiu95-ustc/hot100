# Hot 100 题解

个人 LeetCode Hot 100 学习与练习代码，包含 Java、Python 以及按原始命名保留的无扩展名/文本题解文件。

## 当前内容

- 90 个题解或源码文件；
- 文件名使用“序号 + 题目名称”；
- 保留原始代码内容和文件格式；
- `69最小的括号.txt` 当前为空文件，作为待完成题目的占位；
- IntelliJ IDEA 本地工程配置未提交。

## 使用说明

部分 Java 题解依赖 LeetCode 提供的 `ListNode`、`TreeNode` 等数据结构，适合复制到对应题目的在线编辑器中运行。无扩展名文件按原始学习目录保留，可根据内容补充 `.java` 或 `.py` 扩展名后在本地运行。
